
# Sport.com — Boutique d'équipements de boxe

## Présentation du projet

Sport.com est un site vitrine consacré aux équipements de boxe.

Ce projet a été réalisé en binôme dans le cadre de notre première année de BTS SIO, option SLAM, à Aurlom.

L'objectif est de concevoir un site web avec plusieurs pages, une navigation simple et un affichage adapté aux différentes tailles d'écran.

## Technologies utilisées

- HTML5 : structure et contenu des pages
- CSS3 : mise en forme et responsive design
- Git : gestion des versions
- GitHub : partage du code et travail collaboratif
- Visual Studio Code : environnement de développement

Le projet a été réalisé sans JavaScript.

## Présentation des pages

### Page d'accueil — index.html

Cette page présente le catalogue des équipements de boxe avec les images, les descriptions et les prix des produits.

### Page Qui sommes-nous ? — qui-sommes-nous.html

Cette page présente le magasin Sport.com, son histoire, son équipe, ses informations pratiques et un formulaire de contact.

## Organisation avec Git et GitHub

Nous avons utilisé différentes branches pour développer et améliorer notre site.

Chaque modification importante a été enregistrée avec un commit.

Les Pull Requests nous ont permis de proposer des modifications, de vérifier le travail de l'autre et de préparer les fusions.

## Comment consulter le site ?

1. Télécharger le projet depuis GitHub.
2. Extraire le dossier si le projet est téléchargé en ZIP.
3. Ouvrir le dossier dans Visual Studio Code.
4. Ouvrir le fichier index.html avec Live Server ou dans un navigateur.
