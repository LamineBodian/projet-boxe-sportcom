
# Sport.com — Projet Boxe

## Présentation
Sport.com est un site vitrine fictif consacré à la vente d'équipements de boxe.

Projet réalisé dans le cadre du BTS SIO 1re année à Aurlom.

## Membres du binôme
- Lamine Bodian
- ETHEM

## Fonctionnalités
- Catalogue d'équipements de boxe
- Page Qui sommes-nous
- Présentation de l'équipe
- Informations et horaires du magasin
- Carte OpenStreetMap
- Formulaire de contact
- Affichage adapté aux téléphones

## Technologies utilisées
- HTML5
- CSS3
- Git et GitHub

## Organisation du travail
- Lamine : page Qui sommes-nous, magasin et contact
- ETHEM : page catalogue
- Travail commun : intégration, tests et publication
